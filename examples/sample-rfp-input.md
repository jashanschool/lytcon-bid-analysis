# Sample RFP Input

This is a fictional, public-safe RFP excerpt used to demonstrate the Lytcon analysis flow.

## Context

A municipal administration is looking for a managed workplace service provider for approximately 1,800 workstations.

The provider should operate endpoint devices, support users, manage patches, monitor device health, and provide monthly reporting.

## Requirements

The provider must offer 24/7 support for priority 1 incidents.

Response time for priority 1 incidents must not exceed 30 minutes.

The provider should provide a named service manager.

The provider must provide monthly SLA reporting.

The bidder should describe how endpoint monitoring, patch management, and incident escalation are handled.

The bidder should clearly identify any services that are not included in the standard offering.
